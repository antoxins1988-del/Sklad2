# Склад — облачная сборка APK

1. Создайте GitHub аккаунт и новый репозиторий.
2. Загрузите содержимое этого проекта в репозиторий.
3. Откройте Actions → Build Sklad APK → Run workflow.
4. После сборки скачайте Artifact **Sklad-debug-apk**.
5. Внутри будет **app-debug.apk**.

Сборка выполняется в облаке, поэтому компьютер для сборки не нужен.
Приложение содержит сканирование штрихкода, поиск товара, товары и ячейки, локальное сохранение данных.
